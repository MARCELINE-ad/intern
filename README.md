# DRUGOV Retro Console

Браузерная ретро-консоль на React и TypeScript. Приложение объединяет интерфейс в стиле PSP и три игры, каждая из которых запускается в оформлении своей портативной консоли.

## Возможности

- консоль при открытии страницы выключена и включается отдельной кнопкой;
- главное меню в стиле PSP;
- управление мышью, тачпадом, сенсорным экраном и клавиатурой;
- три игровых режима: «Тетрис», «Ну, погоди!» и «Гонки»;
- автоматическая смена корпуса и оформления для каждой игры;
- зацикленная фоновая музыка для каждого режима;
- включение и выключение музыки кнопками на корпусе;
- часы с реальным временем и индикатор батареи;
- постепенное повышение сложности игр;
- таблица рекордов в «Тетрисе»;
- встроенная страница с инструкцией;
- два юнит-теста Jest.

## Игровые режимы

### Тетрис

Классический тетрис в корпусе PSP. Игрок перемещает и поворачивает фигуры, собирает заполненные горизонтальные линии и получает очки. Скорость падения фигур увеличивается вместе с уровнем.

### Ну, погоди!

Игра в стиле советской «Электроники». Волк должен ловить два яйца, которые независимо скатываются по четырём дорожкам. После трёх промахов игра заканчивается. Скорость яиц постепенно увеличивается.

### Гонки

Аркадные гонки в корпусе Brick Game. Игрок перестраивает машину между полосами и уклоняется от препятствий. Со временем скорость движения увеличивается.

## Запуск проекта

Потребуется Node.js 18 или новее.

1. Установите зависимости:
   npm ci
2. Запустите сервер разработки:
   npm run dev
3. Запуск юнит-тестов
   npm test

## Тесты

Для тестирования используется Jest вместе с ts-jest.

В файле src/gameDifficulty.test.ts находятся две проверки:

1. уровень игры повышается каждые 15 секунд;
2. яйца в «Ну, погоди!» ускоряются, но задержка не становится меньше 260 мс.

Запуск тестов:

    npm test

## Особенности архитектуры

Компонент Console хранит активный экран и преобразует клики по корпусу или нажатия клавиатуры в общие игровые команды. Игры получают одинаковый объект GameCommand, но самостоятельно решают, как обработать направление или подтверждение.

Музыка управляется общим хуком useConsoleAudio. При переходе между режимами трек меняется автоматически, а состояние включённой или выключенной музыки сохраняется.
